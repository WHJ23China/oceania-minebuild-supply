# 使用说明（中文）

## 发送时机

- **首次联系：** 使用 `email-cold-intro.md`，适合矿山、矿业承包商或建筑公司的采购、项目和仓储/物资负责人。首次联系前先确认公司、项目和联系人角色。
- **5–7天未回复：** 使用 `email-follow-up.md`，保持简短，不要重复发送过多信息。
- **WhatsApp或短信：** 使用 `whatsapp-short.md`。选择一个版本即可；只有在有合适的业务联系人、且对方接受此类联系时发送。
- **目标账号整理：** 使用 `target-list-template.md`，先核实公司和公开联系方式，再记录状态。示例名称只是写作示例，不代表真实客户或联系人。

## 每次个性化

- 写明对方公司、国家/地点，以及可能的矿山、工地或项目名称。
- 根据对方职责调整重点：采购强调RFQ和交期，仓储强调补货和规格，项目团队强调交付地点和所需日期。
- 不要承诺库存、价格、交期或认证，除非已经确认。
- 请对方提供品名/规格、数量、交付地点和所需日期；车辆及设备零件仅按RFQ处理。
- 发送前把 `https://whj23china.github.io/oceania-minebuild-supply/` 换成实际网站地址；报价邮箱是 `josephweng58@gmail.com`。
